Transfert de données

  1. En utilisant la fonction de téléversement Galaxy via le navigateur Web à usegalaxy.ca

    1. Cliquez sur Upload Data au en haut du panneau de gauche
    2. Cliquez sur Choose local file et sélectionnez les fichiers ou les déposer dans la fenêtre “Drop files here”
    3. Cliquez sur Start
    4. Cliquez sur Close

  2. En utilisant le script python galaxy-upload

    Si vous téléversez des fichiers à partir d’un environnement Linux sur lequel Python est installé, vous pouvez utiliser le script suivant pour téléverser directement vos fichiers dans un historique de Galaxy.

    1. D’abord générer une clé secrète dans votre compte sur Galaxy sous "User/Preferences/Manage API Key".
    2. Procurez-vous le code sur Github: https://github.com/usegalaxy-ca/galaxy-upload
    3. Suivez les instructions ici: galaxy-upload README.md

  3. En utilisant directement l’API de Galaxy (BioBlend) à l’intérieur de votre code (pour utilisateurs avancés)

    Bioblend est une librairie Python pour interagir avec l’API de Galaxy. Son but est de faciliter la création de script d’automatisation pour exécuter des analyses sur Galaxy, de même que de permettre l’administration à distance de votre environnement dans Galaxy. Vous trouverez ici toute la documentation sur Bioblend.

  4. Transférer en entier un historique d’un serveur Galaxy vers un autre.

    La documentation sur le transfert d’un historique se trouve ici sur le site de formation de Galaxy.

  5. En utilisant Globus pour le transfert et le partage de données vers Galaxy

    Globus est un service de transfert de fichiers fiable, sécuritaire et efficace. Mis au point spécifiquement pour le monde de la recherche, Globus possède une interface facile d’utilisation qui automatise la gestion et le transfert de fichiers entre deux ressources, que ce soit une grappe de calcul, un serveur dans un laboratoire, une station de travail ou un laptop.

    Si vous ne connaissez pas Globus, nous vous suggérons de lire la documentation générale sur Globus ici, et par la suite plus spécifiquement la documentation s'adressant aux utilisateurs canadiens ici

    Pour plus d’information sur comment partager des données dans Globus et sur l’importation et la visualisation de “tracks” voir Globus Collection for Canadian users. UseGalaxy Canada n’est présentement pas configuré comme un “Globus Endpoint”, mais vous pouvez tout de même importer des fichiers dans Galaxy en fournissant des URLs à la fonction de téléversement Galaxy (#1).
