Bienvenue sur UseGalaxy Canada
Le principal serveur Galaxy public canadien

Galaxy est une plateforme web pour l’analyse intensive de données respectant les principes FAIR (Findable, Accessible, Interoperable, Reusable) dont le code source est ouvert. Elle permet entre autres
  • l’utilisation dans des flux de travail (workflows) d’outils de divers domaines grâce à son interface graphique simple;
  • l'exécution de code dans des environnements interactifs;
  • la gestion des données facilitant le partage et la publication des résultats, flux de travail et visualisations;
  • la reproductibilité par la capture des informations nécessaires pour répéter et comprendre les analyses de données.
